# Work Manager 스킬 인증

## 개요

Work Manager 서버(Hono)는 `requireAuthOrSkill` 미들웨어가 두 경로의 인증을 수용한다:
1. **사람 사용자**: Better Auth 세션 쿠키(브라우저에서 로그인한 뒤 자동 전송)
2. **스킬 호출**: `X-Skill-Key` 헤더 + localhost(`127.0.0.1`/`::1`) 출신 요청

스킬은 후자로 인증한다. 키가 일치하고 로컬호스트 출신이면, 서버가 super admin 사용자 컨텍스트로 처리한다.

## SKILL_API_KEY 얻기

키는 서버 `.env.local` 의 `SKILL_API_KEY` 값이다. 스킬 실행 시 셸 환경변수로 이미 주입되어 있다고 가정하고, **필요하면 주인님께 확인**한 뒤 사용한다.

확인 명령:
```bash
# 로드 확인(값 출력은 하지 말 것)
test -n "$SKILL_API_KEY" && echo "OK" || echo "MISSING"
```

값이 없으면 주인님께:
> "`SKILL_API_KEY` 환경변수가 셸에 로드돼 있지 않습니다. `.env.local` 의 값을 현재 쉘에 `export` 하거나, 셸 시작 시 자동 로드되도록 설정해주십시오."

## 키 노출 금지

- 스킬은 키 값을 **평문 출력 / 에디터 파일 저장 / 채팅 메시지**에 절대 쓰지 않는다.
- 항상 `$SKILL_API_KEY` 변수 참조로만 사용.
- 디버깅 중이라도 `echo $SKILL_API_KEY` 금지. 키 존재 여부만 `test -n` 으로 확인.

## 환경 전환 감지

서버 응답이 401이고 `X-Skill-Key` 는 보냈다면, **타깃 환경 불일치**를 최우선 의심:
- 스킬 base URL이 개발(`:8001`) 인데 셸 환경변수가 운영 키로 세팅돼 있을 수 있음
- 반대도 마찬가지

주인님께:
> "현재 base URL은 `<url>`, 사용 중인 키와 환경이 맞는지 확인 부탁드립니다."
