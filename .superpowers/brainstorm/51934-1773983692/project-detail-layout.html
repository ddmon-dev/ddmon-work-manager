개선안 선택

재무 영역의 정보 밀도를 줄이는 방법

A

탭 분리: 기본정보 | 재무

좌측 컬럼 상단에 탭을 두어 "기본정보"와 "재무"를 전환. 기본정보 탭에는 프로젝트 정보만, 재무 탭에는 금액요약 + 세금계산서 + 거래내역 + 입력폼. 한 번에 하나만 보여서 깔끔하지만, 탭 전환 필요.

B

접이식 섹션 (Collapsible)

세금계산서, 거래내역을 접을 수 있는 아코디언으로. 금액요약은 항상 표시, 나머지는 필요할 때 펼침. 전체 맥락을 한 눈에 보되, 디테일은 숨김.

C

요약 카드 + 팝업 상세

금액요약을 컴팩트 카드로 표시하고, 세금계산서/거래내역은 "N건" 배지 클릭 시 팝오버나 드로어로 열림. 거래 입력도 팝오버. 좌측 컬럼이 가장 짧아지지만, 깊이가 생김.
