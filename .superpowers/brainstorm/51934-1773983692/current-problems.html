핵심 문제

1. 역할 분리가 모호

"매출 통계"와 "정산" 모두 미수금을 다루지만, 하나는 보기만, 하나는 처리만. 사용자가 어디로 가야 할지 헷갈림.

2. 동선 단절

Revenue에서 미수금 프로젝트를 보고 → Settlement로 이동 → 같은 데이터를 다시 찾아야 함. 두 페이지 간 연결 없음.

3. 프로젝트 상세 과부하

좌측 컬럼에 기본정보 + 금액요약 + 세금계산서 + 거래내역 + 거래폼이 세로로 쌓여 스크롤 과다. 재무 정보만으로 화면 점유.

4. 정보 계층 부재

전체 매출 → 프로젝트별 → 개별 거래의 드릴다운 구조가 없음. 각 레벨이 독립적으로 존재.

이 문제를 어떻게 접근할까요?

아래에서 선호하는 방향을 선택해주세요

A

통합: Revenue + Settlement → 하나의 "재무" 페이지

탭/섹션으로 통계 + 정산 액션을 한 곳에서. 사이드바 메뉴 1개로 줄임. 통계를 보다가 바로 미수금 처리 가능.

B

허브-스포크: "재무 대시보드" 중심 + 정산 액션 인라인

대시보드에서 KPI 카드(매출/미수금/수금률) → 미수금 클릭 시 바로 인라인 정산. 별도 정산 페이지 제거.

C

유지하되 개선: 2페이지 유지 + 상호 링크 강화

Revenue에서 미수금 클릭 → Settlement 해당 건으로 이동. 각 페이지 역할 명확히 재정의. 네비게이션 그룹 변경.
