# Work Manager: Clients 스킬

Work Manager 앱의 `clients` 엔티티(고객/거래처)를 Hono API 경유로 조작한다.

## 트리거 예시

- "DDP 고객 연락처 좀 알려줘"
- "고객 목록 보여줘"
- "A고객 이메일을 new@foo.com 으로 바꿔줘"
- "B고객 메모에 '2026년 2차 리뉴얼 논의 중' 추가해줘"
- "거래처 ○○ 삭제해도 되나?"

## 실행 절차

### Step 1 — 공통 참조 로드

다음 두 문서를 먼저 **반드시** 읽는다:

1. `../../shared/api-client.md` — base URL, 호출 패턴, 응답 포맷
2. `../../shared/auth.md` — `SKILL_API_KEY` 사용법, 키 노출 금지

### Step 2 — 쓰기 작업이면 위험 게이트 로드

생성/수정/삭제 중 **다음**이면 `../../shared/risk-gate.md` 도 반드시 읽고 프로토콜 준수:

- 삭제 (모든 DELETE)
- `billingClientId` 변경을 동반하는 수정 (이 스킬에서는 직접 다루지 않지만, estimates/projects 에서 발생 가능)

고객 신규 생성, 연락처/이메일/메모 수정은 게이트 없이 바로 진행 가능(주인님이 구체값을 직접 지정한 경우).

### Step 3 — 엔드포인트 확인

`references/endpoints.md` 에서 정확한 경로·요청 바디·쿼리 파라미터 확인.

### Step 4 — 호출 실행

Bash 도구로 `curl` 실행. 응답을 JSON 파싱해 `success` 확인 후 주인님께 **한국어로 요약** 보고.

## 보고 양식

조회:
```
[고객: DDP 에이전시]
연락처: 홍길동 (010-1234-5678, foo@bar.com)
진행 중 프로젝트 N건 / 견적서 M건 (대시보드 참고)
메모 2건 (가장 최근: 2026-03-10 "2차 계약 검토")
```

변경 완료:
```
[완료] 고객 "DDP 에이전시" 이메일: foo@bar.com → new@bar.com
```

## 관련 스킬

- **estimates**: 고객의 견적서 조회 시 함께 발동
- **projects**: 고객의 프로젝트 조회 시 함께 발동
